\## Descripción

Sitio web para la gestión académica de estudiantes. Permite registrar

estudiantes con validación de formulario y visualizar los registros en una

tabla dinámica. Desarrollado con HTML, CSS y JavaScript aplicando ramas,

commits, Pull Requests y resolución de conflictos en Git y GitHub.



\## Tecnologías

\- HTML

\- CSS

\- JavaScript



\## Funcionalidades

\- Formulario de registro con validación de campos.

\- Tabla dinámica que muestra los estudiantes registrados.

\- Botón para mostrar y ocultar información adicional.
