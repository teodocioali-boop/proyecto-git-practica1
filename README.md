## Descripción
Sitio web para la gestión académica de estudiantes. Permite consultar la
información institucional, ver las carreras disponibles, registrar nuevos
estudiantes mediante un formulario con validación y visualizar los registros
en una tabla dinámica. Desarrollado con HTML, CSS y JavaScript aplicando
ramas, commits, Pull Requests y resolución de conflictos en Git y GitHub.

## Tecnologías
- HTML
- CSS
- JavaScript

## Funcionalidades
- Formulario de registro con validación de campos.
- Tabla dinámica que muestra los estudiantes registrados.
- Botón para mostrar y ocultar información adicional.
- Menú de navegación con desplazamiento suave.
- Diseño responsivo con CSS.

## Cómo ejecutar
1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en tu navegador.
